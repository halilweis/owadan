# Owadan Flutter app

The blueprint recommends creating the Flutter shell after the API conventions are stable enough to consume. Sprint 1 therefore keeps this folder as the mobile workspace placeholder.

When the Sprint 1 API envelope/auth contract is finalized, create the app here with:

```bash
flutter create --org tm.owadan --project-name owadan_app .
```

Planned first mobile modules: core networking, localization (tk/ru), auth/OTP, catalog/home, professional discovery.
