# Professional supply foundation

This increment adds the first marketplace supply-side domain:

- professional profile owned by a user account
- draft/pending/verified/rejected verification state
- optional district assignment
- experience and language metadata
- professional services linked to the existing beauty taxonomy
- duration and FIXED/FROM/ON_REQUEST pricing
- ownership checks for professional service updates
- public discovery endpoints restricted to verified active professionals

The next increment should add admin verification and portfolio/media management.
