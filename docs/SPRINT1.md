# Sprint 1 — Foundation

## Goal
Establish the engineering baseline that later identity, professional, portfolio and booking modules depend on.

## Work sequence
1. Repository + coding conventions.
2. Symfony + PostgreSQL local environment.
3. Doctrine migrations and seed data.
4. API response/error convention.
5. Health/readiness checks.
6. User/role + development OTP skeleton.
7. Catalog endpoint.
8. Test and CI baseline.
9. Lock API auth contract, then create Flutter shell.

## Not in Sprint 1
Booking, availability, reviews, payments, chat, marketplace commerce, advanced CRM, AI recommendations.
