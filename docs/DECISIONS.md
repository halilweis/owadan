# Owadan product decisions

- Brand: **Owadan**
- Initial market: Ashgabat, Turkmenistan
- Product: beauty discovery + booking marketplace
- Backend/API: Symfony / PHP 8.4
- Database: PostgreSQL
- Mobile: Flutter
- Web/admin/professional: Symfony (Twig/Stimulus when UI work starts)
- Architecture: modular monolith
- Primary login: phone + OTP
- MVP categories: Hair, Nails, Makeup, Brows & Lashes, Skincare/Cosmetology, Bridal Beauty
- Massage: excluded from MVP
- Online payments: excluded from MVP
- Java/Spring Boot: not used
- React.js: not used
